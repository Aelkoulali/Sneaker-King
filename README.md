# 🗂️ Sneaker King 👟

Sneaker King is a responsive e-commerce-style project built with HTML, CSS, JavaScript, and Bootstrap. It includes a product catalog with client-side filtering.

## ✅ Key Features
- E-commerce product UI (catalog layout)
- Responsive design (Bootstrap)
- Product filter using JavaScript (e.g., category/price/search — update based on your filters)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- Bootstrap

## ▶️ How to Run
1. Open `index.html` in your browser.
